New Zealand: five op-ed evidence packs

70 charts from public data, with downloadable plotting data and source links. Snapshot cutoff: 14 October 2026. Observed statistics, context proxies and scenarios are labelled separately.

These charts test measurements; they do not make a policy argument. Read each caveat before comparing series. The measurement notes identify missing data for stronger claims. Download the catalogue.

Coverage note: the workforce-sector CSV linked from the PSC 2025 page ends in 2023. Departmental FTEs extend to March 2026. Tax on savings uses an assumed 5% return because RBNZ automated downloads were inaccessible; it is not a measured deposit-return series.

Benefit history: additional B11-B29 charts cover quarterly counts from 2008, actual Treasury expenses from 2001, and selected archival observations from 1940. The history notes explain backcasts, overlaps and accounting/coverage breaks.
