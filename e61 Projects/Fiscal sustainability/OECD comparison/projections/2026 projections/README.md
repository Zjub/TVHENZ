# 2026 fiscal projections

This folder contains a self-contained, modular refresh of the Australian fiscal
projection workflow. It keeps official forecasts, bottom-up projections,
top-down time-series projections, forecast checks, debt arithmetic, figures and
documentation separate.

Run the complete workflow from this folder with:

```powershell
& "C:\Program Files\R\R-4.5.1\bin\Rscript.exe" --vanilla "run_all.R"
```

The workflow downloads current official inputs when they are unavailable
locally. Set the environment variable `REFRESH_DATA=true` to force a new
download.

## Script order

1. `scripts/01_download_data.R` downloads official ABS, Centre for Population,
   PBO and Budget inputs.
2. `scripts/02_clean_data.R` builds consistent annual historical and projection
   datasets and runs data checks.
3. `scripts/03_assumptions.R` creates central and sensitivity assumptions.
4. `scripts/04_official_forecast.R` extracts the consolidated official forecast
   anchor.
5. `scripts/05_download_bottom_up_drivers.R` downloads official ABS public-sector
   wage-price series for the data-enhanced bottom-up sensitivity.
6. `scripts/10_bottom_up_projection.R` projects the baseline spending paths by
   GFS purpose using fixed demographic exposure rates.
7. `scripts/11_bottom_up_data_enhanced.R` projects a separate evidence-weighted
   variant using the same demographic exposures, online wage-price series and
   shrunk historical residual-intensity estimates.
8. `scripts/20_top_down_projection.R` estimates the focused four-model set:
   old-Shapley structural OLS, revised hybrid, real-spending-per-capita
   differences, and a COVID-adjusted ARIMA benchmark.
9. `scripts/21_shapley_attribution.R` averages incremental fitted contributions
   over every ordering of the structural factors. It is an attribution diagnostic,
   not an eighth forecasting model.
10. `scripts/34_four_model_assessment.R` performs comparable in-sample,
    rolling-forecast, estimation-window, residual, collinearity and exact
    finite-sample cointegration checks for those four models.
11. `scripts/40_revenue_and_debt.R` builds revenue scenarios and debt paths.
12. `scripts/50_graphs.R` writes the full figure suite, including direct
    bottom-up versus top-down comparisons.
13. `scripts/51_bottom_up_comparison_graphs.R` compares the baseline and
    data-enhanced bottom-up estimates by scenario and purpose.
14. `scripts/53_four_model_figures.R` creates the focused top-down comparison
    figures for Word and LaTeX.
15. `scripts/55_age_profile_sensitivity.R` re-estimates the top-down models with
    a fixed-weight age-expenditure profile in place of the separate age shares
    and writes matched fit, coefficient and projection comparisons.
16. `scripts/56_interest_treatment_sensitivity.R` compares inclusion of all
    interest with exclusion of conventional or total interest.
17. `scripts/63_four_model_report.R` writes the focused five-model assessment
    and bottom-up development note.
18. `scripts/64_age_profile_note.R` writes a Word methods note auditing the
    profile weights, evidence base, literature and sensitivity results.
19. `scripts/65_top_down_literature_review.R` writes a short Word literature
    review of aggregate top-down spending forecast and projection methods.
20. `scripts/66_interest_treatment_note.R` writes the ABS accounting and model
    results explainer for the interest treatment.
21. `scripts/62_bottom_up_comparison_report.R` writes a Word report comparing
    the two bottom-up methods and documenting the online data and limitations.

The reported top-down baseline uses separate shares aged 0-14 and 65+. Set
`topdown_demographic_specification <- "expenditure_profile"` in
`scripts/00_config.R` to use the age-expenditure profile in the ordinary model
workflow. Script 55 always estimates both treatments for a matched comparison,
regardless of that switch.

The aggregate top-down outcome has a separate three-way interest switch in
`scripts/00_config.R`. `exclude_other_interest` is the preferred setting;
`exclude_total_interest` and `include_interest` are retained as sensitivities.
Script 56 estimates all three treatments, and script 66 writes the associated
ABS accounting and model-results explainer.

The colleague-facing technical note is
`documentation/fiscal_projection_model_selection.tex`. It gives the equations
for the four top-down specifications, forecast-error evidence, the per-capita
cointegration test, both bottom-up methods, and a final cross-model comparison.
Its figures are regenerated by script 53. Flat PNG copies are written to
`documentation/figures/`, and every LaTeX image reference uses
`figures/<filename>.png` to match the Overleaf folder layout.

Compile the note from the `documentation` directory with a standard LaTeX
distribution, for example by running `pdflatex fiscal_projection_model_selection.tex`
twice. The current machine does not include a LaTeX engine, so the workflow
generates and validates the source and figures but does not build a PDF.

The ECM validation stage additionally requires the CRAN packages `ARDL`,
`urca`, `lmtest` and `strucchange`.

## Output layout

- `data/raw/`: downloaded source files and a source manifest.
- `data/processed/`: cleaned and model-ready datasets.
- `outputs/tables/`: projections, diagnostics and comparison tables.
- `outputs/figures/`: grouped bottom-up, top-down, comparison and debt figures.
- `documentation/`: generated Word report.

The top-down national-accounts expenditure concept and the PBO/GFS official
expense concept are not identical. The workflow preserves this distinction,
reports the bridge at the join, and anchors model growth rates rather than
silently treating the levels as interchangeable.
